## 這套教材為誰編寫？

你能夠獨立搭建前端項目，做過接口聯調，熟悉 Promise 與 async/await，瞭解 TypeScript 基礎類型，但還沒有親自實現後端或數據庫。這就是本教材的讀者起點。

我們不要求你先學 Express，也不把複雜類型體操作為門檻。已有工程經驗會幫助你理解項目組織、測試和協作，但不能替代第一次設計表結構、事務、權限與部署流程的實踐。教材會把這些陌生職責逐步講清，而不是用一張庫名和 API 表格代替教學。

## 學習目標：能交付，而不只是能看懂

最終目標是：允許查閱文檔，能夠根據需求獨立實現、測試、部署和維護一個可供受邀用戶使用的中小型後端，並完成一次沒有逐步實現教程的新需求。

“讀完所有頁面”不是完成標準。每個階段都需要實際產物、成功與失敗場景、驗收步驟，以及對設計的解釋。後續開放公共註冊等功能還需要額外的安全與運維驗收，不能把演示程序直接當成完整產品。

> **改造狀態（2026-09-29）：** 39 章均已提供英文、簡體、繁體完整正文與配套材料。驗收記錄區分本機實際運行的實驗，以及需要受控 Linux、容器、HTTPS 或託管交付環境的待驗證項目。教材內容完成不自動代表公網上線成功，也不代表讀者已經畢業。

## 怎樣使用本教材？

一個知識點通常沿著這樣的過程展開：

1. 先提出一個真實問題，解釋為什麼需要這個知識。
2. 借用你熟悉的前端經驗建立聯繫，同時說明類比失效的邊界。
3. 解釋概念與運行機制，再給出必要的語法和 API。
4. 運行完整例子，預測並解釋輸入、輸出及失敗行為。
5. 完成帶提示的修改，然後獨立完成變式需求。
6. 用測試或明確操作驗收，之後再查看分開放置的參考答案。

從 L10 開始建立自己的產品倉庫。後續 API、PostgreSQL、身份、對象權限、異步和運維實驗都要回到這份倉庫，保留自己的遷移、測試、發布、回退和恢復記錄；獨立實驗用於理解機制，不能直接替代完整產品整合。

完整的[貫穿項目指南](/zh-tw/docs/js2py/project-integration)把每個階段如何接回同一份產品、怎樣驗收真實發布和長期維護寫成可執行清單。

使用[官方來源矩陣](/zh-tw/docs/js2py/official-sources)區分上游行為、鎖定版本和課程自定義契約。

使用[生產發布與維護運行手冊](/zh-tw/docs/js2py/deployment-runbook)把 O 階段證據接入真實目標環境。

不是所有例子都適合在網頁運行。純語法可以使用瀏覽器實驗；多文件、依賴、數據庫和 Web 服務應在明確的本地環境中執行。配置文件、故意錯誤的例子和服務程序不能僅因有一個編輯器，就被稱為“點擊即可運行”。

## 分階段的能力路線

| 階段 | 需要形成的能力 | 產物 |
| --- | --- | --- |
| Python 基礎 | 語言差異、函數、類型、模塊、異常、資源與測試 | 可復現的本地任務程序 |
| HTTP 與 FastAPI | 接口契約、驗證、響應、路由、依賴與配置 | 可聯調的 API |
| 數據庫 | SQL、關係、約束、事務、ORM 與遷移 | 不靠內存保存狀態的服務 |
| 多用戶 | 身份、密碼、憑證失效、對象級權限 | 不會跨用戶洩露數據的應用 |
| 可靠性 | API/數據庫測試、異步邊界、超時與故障處理 | 可以解釋和驗證失敗行為的項目 |
| 交付與維護 | 部署、日誌、備份恢復、迭代與回退 | 受控真實上線與獨立新功能 |

先把同步後端的基本行為做正確，再學習有具體用途的異步。數據分析、複雜元類、高級泛型和分佈式任務等內容可以作為選修，不阻斷第一個項目的交付。這個順序不是壓縮基礎，而是避免讓不必要的複雜度搶在必要知識之前。

## 先後順序比一次學多少更重要

新的 Python 主線按小步驟展開：**第一次運行 → 名稱與值 → 容器 → 控制流 → 函數 → 異常 → 模塊 → 文件/JSON → 環境與依賴 → 基礎測試 → 第一個獨立可復現項目**。隨後再補齊類型、類、裝飾器和資源生命週期，進入服務端與 FastAPI。

每一步都有當前知識足以解釋的小程序，不是先讀完整本語法書才實踐，也不是先搭工程再長期欠下解釋。各章按前置能力驗收，不按固定週數推進。按目錄逐章通過能力驗收，而不是讀過標題就算掌握。環境準備、憑證處理、遷移安全和恢復都有自己的教學與證據；後續章節不會無聲地把本地演示升級成生產服務。

## 從哪裡開始？

從[第 00 章：讀懂並運行第一份腳本](/zh-tw/docs/js2py/module-00-python-introduction)開始。本章只用 uv 準備和選擇 CPython 3.13，不教學整套工程配置；虛擬環境、鎖文件和 pytest 在具備語言與模塊基礎之後再系統學習。

普通 Python 函數使用 `def`，並不需要 `self`；實例方法才會涉及顯式的實例參數。Python 的 async/await 與 JS 表面相似，也不表示調度和執行行為完全一樣。我們會通過可驗證的例子建立準確聯繫，不用一句“對應關係”抹平差異。

學習時間可以不固定。每次結束時記錄當前代碼狀態、通過的測試、仍不理解的問題和下次第一步。按能力驗收推進，而不是按週數趕進度。
