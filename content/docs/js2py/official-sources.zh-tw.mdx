## 如何使用這張表

下面的連結是課程機制的主要一手資料。課程會在這些機制之上選擇業務契約、欄位、狀態碼、保留期限和驗收場景；課程契約不是框架預設值。

升級依賴時，記錄新版本，閱讀對應官方資料，重跑受影響的失敗路徑、遷移、授權、回退和恢復，並更新產品記錄。當前文件連結不等於舊鎖文件與新版本行為完全相同。

## 不能誤當成上游預設值的課程契約

- `/tasks`、項目/成員/任務欄位、狀態碼、分頁上限、404/403 策略和 PATCH 規則是課程契約。
- 不透明 Bearer 會話是教學實現。選擇 JWT、Cookie 或外部身份服務時，必須重新設計認證和撤銷。
- 冪等保留期、受邀用戶上限、備份保留、RPO/RTO 和告警閾值是產品決策，不是 FastAPI、PostgreSQL 或 HTTP 的普遍保證。
- 本地 trust、回環 socket、合成數據和短命歸檔是實驗邊界，不等於生產認證、公網網絡或災難恢復。

## 升級後的證據

保留舊/新鎖文件、官方版本連結、遷移兼容結果、API 和授權回歸、回退結果、恢復結果及未解決風險。目標環境不可用時記錄 `blocked` 或 `not_run`，不能從本地通過推導生產就緒。
