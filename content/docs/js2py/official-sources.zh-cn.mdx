## 不能误当成上游默认值的课程合同

- `/tasks`、项目/成员/任务字段、状态码、分页上限、404/403 策略和 PATCH 规则是课程合同。
- 不透明 Bearer 会话是教学实现。选择 JWT、Cookie 或外部身份服务时，必须重新设计认证和撤销。
- 幂等保留期、受邀用户上限、备份保留、RPO/RTO 和告警阈值是产品决策，不是 FastAPI、PostgreSQL 或 HTTP 的普遍保证。
- 本地 trust、回环 socket、合成数据和短命归档是实验边界，不等于生产认证、公网网络或灾难恢复。

## 升级后的证据

保留旧/新锁文件、官方版本链接、迁移兼容结果、API 和授权回归、回退结果、恢复结果及未解决风险。目标环境不可用时记录 `blocked` 或 `not_run`，不能从本地通过推导生产就绪。
