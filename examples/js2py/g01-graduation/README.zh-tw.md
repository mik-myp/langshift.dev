# G01 — 獨立任務評論需求與證據包

核驗日期：2026-09-28。本包不是後端參考實現，也不是可以替學生項目執行驗收的測試套件。前置 O06 的恢復與受控發佈證據必須由主線/評閱者核實；前章缺環境不能被本包自動標成通過。

## 交付是什麼

任務評論是 capstone 標籤擴展的等價受控變式，不要求兩者同時完成。新增的實質複雜度是作者與項目 owner 的不同權限、成員撤銷、版本化編輯、撤回後不可復活、重複請求和響應不明，以及已有數據升級、回退、恢復和受邀反饋。學生自行選擇並論證模型、接口、事務機制、遷移和交付策略；包裡沒有這些實現答案。

- `requirements.json`：機器可讀產品契約，版本 g01-comments-v1。邏輯事實不等於給定數據庫表。
- `fixtures/actors-and-data.json`：純合成主體和對象、內容邊界；邏輯標籤不是規定的實際 ID，也不是生產導入腳本。
- `scenarios.json`：S01–S24 的前提、行為與預期、硬門檻，不是已運行的自動化測試。
- `rubric.json`：人工評閱六維 100 分、參考線 80 及不能被分數抵消的門檻。
- `templates/evidence.json`：未填學生報告，24 場景均 not_run；四種完成聲明分離。
- `templates/fixture-bindings.json`：把合成邏輯標籤映射到學生測試模型；不要填憑證。
- `templates/checkpoint.json`：中斷時的版本、獨佔目標、已證實事實、下一份證據與資源停止記錄。
- `templates/reviewer-record.json`：未填的人工評閱記錄；不預填畢業或公網批准。
- `check_evidence.py`：可選的材料格式檢查器，僅標準庫。
- `tests/test_materials.py`：格式/目錄數據的單元測試，不是評論 API 測試。
- `sources.json`、三語 README、`FILES.json`：來源、運行約定和打包 allowlist。

## 不運行後端也能檢查包，但不能據此畢業

只閱讀 JSON/Markdown 無須任何運行環境。若要運行可選工具，本次實測 Python 3.13.15，`.python-version` 記錄該基線；沒有外部依賴，因此不提供虛假的依賴鎖，也不要求 uv、pytest、數據庫、Docker 或前端軟件。使用已有 Python，不安裝系統服務。

工作目錄是解壓後的 g01-graduation：

```bash
python3 --version
python3 check_evidence.py templates/evidence.json
python3 -m unittest discover -s tests -v
```

默認模板的確定輸出：

```text
{"artifact_files_verified": false, "backend_verified": false, "format_valid": true, "graduation_awarded": false, "public_operation_verified": false, "scenario_status_counts": {"blocked": 0, "fail": 0, "not_run": 24, "pass": 0}}
```

應有 15 項材料單元測試通過，耗時不固定。作者從 allowlist ZIP 解壓後也會運行這些檢查。它們驗證缺場景、重複、非法引用/路徑、虛假時間、損壞 JSON 和合成數據關聯等，不驗證任何學生後端。真實學生 24 場景仍為 not_run。

格式檢查器返回 0 僅指格式可接受；非法材料返回 1。它不打開證據文件核對摘要，不驗證材料真實，不訪問網絡或數據庫，不掃描所有秘密，也不能宣佈評分合格、畢業或部署。單元測試在內存中故意構造一份虛構報告，證明形式正確不代表後端正確；該測試不是上線記錄。

## 如何表達材料，不規定如何實現系統

保留原模板作為空白基線，把自己的報告放在另一個提交目錄。每條實際執行聲明應能關聯代碼/結構版本、獨佔環境、時間、輸入、響應、持久狀態與經過脫敏的證據路徑。pass 是作者聲明，仍須評閱；fail 保留反例；blocked 寫清外部條件與責任人；not_run 不填預期成功或偽造時間。

併發證據必須顯示真實交錯，響應丟失不能用“第一次沒提交”替代，恢復必須是隔離目標中的真實恢復。只有備份文件、空庫遷移、綠色截圖、覆蓋率數字或最終一行記錄都可能不足。正文三處摺疊核對區解釋這些評閱反例，不提供後端實現步驟。

包內的相對路徑/sha256 只幫助定位材料；格式工具不會驗證文件內容。提交者必須自行確認引用、脫敏和可重現性。不要包含 Token、密碼、私鑰、完整環境變量或真實私密正文。沒有 approved 主機/域名/預算/憑證時，不得聲稱公網部署；受邀試用也只在條件滿足後進行。

## 暫停與恢復

檢查點按材料成熟度記錄，不指定“先建表再寫路由”。保存實際版本、最後命令、最後證實事實、未解決問題、下次要收集的證據以及自己停止的資源。恢復時對照當前狀態重新確認，不假設上次結果仍成立。本包本身不啟動服務、不創建賬戶、不修改數據庫；運行檢查器沒有集群需要清理。

O06 未核實或沒有受邀試用環境時保留 blocked；本包不會修改共享章節狀態。獨立答辯要披露輔助工具的使用，能解釋一個真實定位過程，並應對評閱者臨時給出的業務變化。

## 四個狀態與已知侷限

課程內容完成、作者參考驗證、學生畢業、真實公網運營必須分別記錄。本包只證明作者材料工具已執行，不證明任何學生畢業。人工評閱需同時滿足 O06、全部 24 場景的必需行為、硬門檻、評分和獨立能力；既不能用漂亮文檔抵消越權，也不能由腳本自動批准。

未運行學生應用、遷移、對象權限、併發業務、發佈/回退、數據庫恢復或真實試用；沒有公網上線或運營證據。材料工具不是保密審計、安全認證或法律合規認證。其他章節的欠缺不得在此越級補成已驗收。
