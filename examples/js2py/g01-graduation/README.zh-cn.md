# G01 — 独立任务评论需求与证据包

核验日期：2026-09-28。本包不是后端参考实现，也不是可以替学生项目执行验收的测试套件。前置 O06 的恢复与受控发布证据必须由主线/评阅者核实；前章缺环境不能被本包自动标成通过。

## 交付是什么

任务评论是 capstone 标签扩展的等价受控变式，不要求两者同时完成。新增的实质复杂度是作者与项目 owner 的不同权限、成员撤销、版本化编辑、撤回后不可复活、重复请求和响应不明，以及已有数据升级、回退、恢复和受邀反馈。学生自行选择并论证模型、接口、事务机制、迁移和交付策略；包里没有这些实现答案。

- `requirements.json`：机器可读产品契约，版本 g01-comments-v1。逻辑事实不等于给定数据库表。
- `fixtures/actors-and-data.json`：纯合成主体和对象、内容边界；逻辑标签不是规定的实际 ID，也不是生产导入脚本。
- `scenarios.json`：S01–S24 的前提、行为与预期、硬门槛，不是已运行的自动化测试。
- `rubric.json`：人工评阅六维 100 分、参考线 80 及不能被分数抵消的门槛。
- `templates/evidence.json`：未填学生报告，24 场景均 not_run；四种完成声明分离。
- `templates/fixture-bindings.json`：把合成逻辑标签映射到学生测试模型；不要填凭证。
- `templates/checkpoint.json`：中断时的版本、独占目标、已证实事实、下一份证据与资源停止记录。
- `templates/reviewer-record.json`：未填的人工评阅记录；不预填毕业或公网批准。
- `check_evidence.py`：可选的材料格式检查器，仅标准库。
- `tests/test_materials.py`：格式/目录数据的单元测试，不是评论 API 测试。
- `sources.json`、三语 README、`FILES.json`：来源、运行约定和打包 allowlist。

## 不运行后端也能检查包，但不能据此毕业

只阅读 JSON/Markdown 无须任何运行环境。若要运行可选工具，本次实测 Python 3.13.15，`.python-version` 记录该基线；没有外部依赖，因此不提供虚假的依赖锁，也不要求 uv、pytest、数据库、Docker 或前端软件。使用已有 Python，不安装系统服务。

工作目录是解压后的 g01-graduation：

```bash
python3 --version
python3 check_evidence.py templates/evidence.json
python3 -m unittest discover -s tests -v
```

默认模板的确定输出：

```text
{"artifact_files_verified": false, "backend_verified": false, "format_valid": true, "graduation_awarded": false, "public_operation_verified": false, "scenario_status_counts": {"blocked": 0, "fail": 0, "not_run": 24, "pass": 0}}
```

应有 15 项材料单元测试通过，耗时不固定。作者从 allowlist ZIP 解压后也会运行这些检查。它们验证缺场景、重复、非法引用/路径、虚假时间、损坏 JSON 和合成数据关联等，不验证任何学生后端。真实学生 24 场景仍为 not_run。

格式检查器返回 0 仅指格式可接受；非法材料返回 1。它不打开证据文件核对摘要，不验证材料真实，不访问网络或数据库，不扫描所有秘密，也不能宣布评分合格、毕业或部署。单元测试在内存中故意构造一份虚构报告，证明形式正确不代表后端正确；该测试不是上线记录。

## 如何表达材料，不规定如何实现系统

保留原模板作为空白基线，把自己的报告放在另一个提交目录。每条实际执行声明应能关联代码/结构版本、独占环境、时间、输入、响应、持久状态与经过脱敏的证据路径。pass 是作者声明，仍须评阅；fail 保留反例；blocked 写清外部条件与责任人；not_run 不填预期成功或伪造时间。

并发证据必须显示真实交错，响应丢失不能用“第一次没提交”替代，恢复必须是隔离目标中的真实恢复。只有备份文件、空库迁移、绿色截图、覆盖率数字或最终一行记录都可能不足。正文三处折叠核对区解释这些评阅反例，不提供后端实现步骤。

包内的相对路径/sha256 只帮助定位材料；格式工具不会验证文件内容。提交者必须自行确认引用、脱敏和可重现性。不要包含 Token、密码、私钥、完整环境变量或真实私密正文。没有 approved 主机/域名/预算/凭证时，不得声称公网部署；受邀试用也只在条件满足后进行。

## 暂停与恢复

检查点按材料成熟度记录，不指定“先建表再写路由”。保存实际版本、最后命令、最后证实事实、未解决问题、下次要收集的证据以及自己停止的资源。恢复时对照当前状态重新确认，不假设上次结果仍成立。本包本身不启动服务、不创建账户、不修改数据库；运行检查器没有集群需要清理。

O06 未核实或没有受邀试用环境时保留 blocked；本包不会修改共享章节状态。独立答辩要披露辅助工具的使用，能解释一个真实定位过程，并应对评阅者临时给出的业务变化。

## 四个状态与已知局限

课程内容完成、作者参考验证、学生毕业、真实公网运营必须分别记录。本包只证明作者材料工具已执行，不证明任何学生毕业。人工评阅需同时满足 O06、全部 24 场景的必需行为、硬门槛、评分和独立能力；既不能用漂亮文档抵消越权，也不能由脚本自动批准。

未运行学生应用、迁移、对象权限、并发业务、发布/回退、数据库恢复或真实试用；没有公网上线或运营证据。材料工具不是保密审计、安全认证或法律合规认证。其他章节的欠缺不得在此越级补成已验收。

## 来源与打包

2026-09-28 核验，必要官方来源记录在 sources.json：OWASP API1 对象授权、PostgreSQL 18 SQL Dump/恢复、RFC 9110 幂等方法。只用于解释验收边界，不为引用而新增实现要求。

FILES.json 与仓库同级 `g01-graduation-files.json` 是相同的逐文件 allowlist。ZIP 只含需求、合成数据、模板、工具和文档；不包含 submission、cache、用户材料、凭证或数据库。主线负责 canonical loader `getGraduationExample`、导航/状态和 `/learning-assets/js2py/g01-graduation.zip` 发布注册；本包不修改共享文件。
